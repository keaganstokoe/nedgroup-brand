# nedgroup-brand

Brand assets, house-style contract and deck tooling used by Nexus agents when producing Nedgroup Investments collateral. Demo/prototype use.

| File | Purpose |
|---|---|
| `logo-nedgroup-green.png` | Official stacked logo, deep green. Do not recolour or stretch. |
| `STYLE.md` | House-style contract (palette, type, voice, disclaimer). |
| `SKILL.md` | The agent skill text (mirror of the shared Nexus skill `nedgroup-house-style`). |
| `Nedgroup-Investments-template.pptx` | 16:9 PowerPoint template, 7 layouts matching the commentary grammar. Uploaded to SlidesGPT as template `9c3383ed-fc5c-4f52-b5bf-ae773ca18b6a`. |
| `fill_template.py` | `python3 fill_template.py Nedgroup-Investments-template.pptx content.json out.pptx` — fills the template verbatim from JSON. Needs `pip install python-pptx`. |
| `example-content.json` | Worked content file (Flexible Income Fund, Q2 2026). |
| `preview/` | Rendered previews. |

Raw URLs: `https://raw.githubusercontent.com/keaganstokoe/nedgroup-brand/master/<file>`
